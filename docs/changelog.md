# 版本记录

## 2.0.0.dev2 — 开发中

- 标准 HID 电量报告读取及原生描述符解析。
- 首批厂商适配：Arctis 7/2019、指定 Logitech 接收器上的 HID++ 2.0 1000/1004 电量功能。
- 独立工作进程、单接口超时、总扫描预算及分阶段 UI 更新。
- 新增无需 Qt 的诊断导出和兼容性说明；厂商设备实机验证待完成。

## 2.0.0.dev1 — 开发中

- 目标 2.0.0：按 Windows 属性、标准 HID、厂商协议三层适配无线设备。
- 第一层扫描扩展到 USB/HID，按设备实例而非名称去重。
- 空结果不再触发慢速回退；增加可独立扩展的数据源聚合接口。
- 尚未发布；标准 HID 和厂商协议未完成。

## 1.0.0 — 2026-09-07

首个正式 Release 版本。

- 支持读取 Windows 蓝牙设备电量。
- 提供透明桌面小组件、托盘菜单和低电量提醒。
- 修复首次渲染时文字被压缩的问题。
- 增强 Win+D 后的窗口恢复逻辑。
- 完成标准化项目目录、测试和正式打包流程。
