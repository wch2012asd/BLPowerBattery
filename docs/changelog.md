# 版本记录

## 1.0.2 — 2026-11-24

- 新增机械师 MACHENIKE L8 Air 星闪三模鼠标（VID 369B，官方驱动 12 个 PID）2.4G 电量读取，实机读数与官方驱动一致。
- 协议来自官方驱动日志：厂商通道 FFA0/usage 2，命令 A0 50（report_device_status），电量位于应答字节 [8]。
- 仅查询电量，不写入设备配置；充电状态字段未确认，暂显示未知。

## 1.0.1 — 2026-11-18

- 新增 ASUS ROG Omni 接收器（VID 0B05 / PID 1ACE）2.4G 设备电量读取，协议样本测试通过。
- 隐藏 Windows 显示“未连接”的蓝牙设备，只显示当前连接的设备。
- 电量 0% 视为休眠/无数据哨兵值不再显示，避免出现全黑进度条卡片。
- 设备列表为空时显示“未检测到无线设备”居中占位内容。

## 2.0.0.dev2 — 开发中

- 标准 HID 电量报告读取及原生描述符解析。
- 首批厂商适配：Arctis 7/2019、指定 Logitech 接收器上的 HID++ 2.0 1000/1004 电量功能。
- 独立工作进程、单接口超时、总扫描预算及分阶段 UI 更新。
- 新增无需 Qt 的诊断导出和兼容性说明；厂商设备实机验证待完成。

## 2.0.0.dev1 — 开发中

- 目标 2.0.0：按 Windows 属性、标准 HID、厂商协议三层适配无线设备。
- 第一层扫描扩展到 USB/HID，按设备实例而非名称去重。
- 空结果不再触发慢速回退；增加可独立扩展的数据源聚合接口。
- 尚未发布；标准 HID 和厂商协议未完成。

## 1.0.0 — 2026-09-07

首个正式 Release 版本。

- 支持读取 Windows 蓝牙设备电量。
- 提供透明桌面小组件、托盘菜单和低电量提醒。
- 修复首次渲染时文字被压缩的问题。
- 增强 Win+D 后的窗口恢复逻辑。
- 完成标准化项目目录、测试和正式打包流程。
